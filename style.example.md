# Composer style notes

This file is your personal scratchpad — standing preferences, prior corrections, and "what's been working." Claude reads it before composing so it can carry guidance across sessions.

It starts empty. Add entries as you go. The shape that's worked well is:

- **Vary the archetypes** — list keys, archetypes, tempos, and feel-arcs you've over-used recently, and the rotations to reach for instead.
- **Confirmed working** — short notes about what landed (e.g. "minor keys with modal harmony — confirmed 2026-05-14 after a 'too happy' major-key piece").
- **Avoid** — anything you've reacted negatively to (e.g. "no 4-chord modal loops; even Aeolian anthem reads as pop").

A useful self-check before generating: "Could I describe how this song's harmony differs from the last one in one sentence?" If not, rework it.
